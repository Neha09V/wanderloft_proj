## ✨ About WanderLoft

**WanderLoft** is a full-stack travel platform inspired by modern vacation-rental and travel communities.

It combines two experiences into one platform:

🏡 **Travel Discovery**
Explore stays, destinations, categories, locations and travel experiences.

🌍 **Travel Community**
Share travel moments, upload photos, write experiences and discover stories from other travelers.

The platform also provides user authentication, listing management, favorites, reviews, ratings, profile management and location-based exploration.

# 🔐 Authentication Flow

```text
User
 │
 ▼
Signup / Login
 │
 ▼
Passport.js
 │
 ▼
Authentication
 │
 ▼
Session Created
 │
 ▼
connect-mongo
 │
 ▼
MongoDB Atlas
 │
 ▼
Protected Routes
```

### Authentication workflow

1. User creates an account.
2. User credentials are processed through Passport.js.
3. An authenticated session is created.
4. Session data is persisted using `connect-mongo`.
5. Protected routes verify authentication before allowing access.
6. Flash messages provide feedback for successful or failed operations.

# ⚙️ Environment Variables

Create a `.env` file in the project root:

```env
ATLASDB_URL=your_mongodb_connection_string
SECRET=your_session_secret
CLOUDINARY_CLOUD_NAME=your_cloudinary_name
CLOUDINARY_KEY=your_cloudinary_key
CLOUDINARY_SECRET=your_cloudinary_secret
```

> Never commit your `.env` file or production credentials to GitHub.

# 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/your-username/WanderLoft.git
cd WanderLoft
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file and add the required credentials.

### 4. Start the application

```bash
npm start
```

For development:

```bash
npm run dev
```

### 5. Open in browser

```text
http://localhost:8080
```
